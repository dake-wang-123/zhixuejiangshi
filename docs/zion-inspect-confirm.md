# 第10步之后必须确认，才能进检验

十步交付法走完不要自动请求检验1。先停在确认卡，讲师点「确认进入」或回复「好的 / 开始」再进检验。检验1完成后再确认一次，才进检验2。

**不要**给「智学对话」行为流加新入参。确认后的指令写进 `user_message`。

---

## 第一部分：变量、确认卡、绑定

| 页面变量 | 类型 | 含义 |
| --- | --- | --- |
| `current_phase` | 文本 | `learning` 十步中；`inspection` 已确认进检验 |
| `inspection_step` | 数字 | 1=检验1，2=检验2 |
| `inspectWait` | 文本 | `exam1` 等确认进检验；`exam2` 等确认进检验2；空=不在等 |
| `current_step` | 数字 | 十步未确认前保持 **10**，确认后 11 / 12 |
| `finished` | 布尔 | 1–10 都打勾 |
| `exam1Done` / `exam2Done` | 布尔 | 两段检验是否完成 |

### 确认卡（画布）

十步进度条：`current_phase != inspection` 时显示。  
检验小进度：`current_phase == inspection` 时显示「检验1 讲课 / 检验2 说课」。

| 显示条件 | 卡片文案 | 按钮 |
| --- | --- | --- |
| `inspectWait == exam1` | 恭喜你已完成十步交付法！是否进入实战检验环节？ | 确认进入 → `startExam1` |
| `inspectWait == exam2` | 检验1已完成。是否进入检验2（说课训练）？ | 确认进入检验2 → `startExam2` |
| `exam2Done` | 全部通关 | 查看学习记录 |

输入框：当 `inspectWait` 有值且讲师发「好的 / 是 / 开始 / 确认进入」时，走同一条确认，不要当普通闲聊发给扣子。

卡片底 `#EEF1FE`，主按钮 `#4B6EF5` 白字，圆角 16rpx。

---

## 第二部分：行为流节点

不要改智学对话的四个入参。

1. **10 步结束拦截**  
   Run Code 抽出 `next_step` 后：若 `completed >= 10` 或 `[下一关: 11]` 或 `【十步完成】` 或 `[等待确认: 检验]`：  
   - `current_step = 10`  
   - `finished = true`  
   - `inspectWait = exam1`  
   - `current_phase = learning`  
   - **禁止**再请求「请开始第11步」或检验1。

2. **确认后跳转**  
   按钮或确认口令 → 请求智学对话，`user_message` 用：  
   `讲师已确认，请开始检验1的内容`  
   页面变量：`current_phase=inspection`，`inspection_step=1`，`inspectWait=''`。  
   本轮 `command` 只写在进度上下文里，不要加行为流入参。

3. **检验1 结束**  
   回复含 `【检验1完成】` 或 `[检验进度: 1/2]` 且已出稿：  
   - 写入「学习成果」：讲课逐字稿、诊断报告（`lesson_code` + 登录用户行权限，不要传 `user_id` 入参）  
   - `exam1Done=true`，`inspectWait=exam2`  
   - **禁止**自动请求检验2。

4. **确认进检验2**  
   `user_message`：`讲师已确认，请开始检验2的内容`  
   `inspection_step=2`。

5. **检验2 结束**  
   `【检验2完成】` 或 `[检验进度: 2/2]`：  
   - 写入说课逐字稿、PPT大纲  
   - `exam2Done=true`，`inspectWait=''`，展示全部通关。

请求锁：`sending==true` 时确认按钮无效。

---

## 第三部分：扣子提示词（整段粘贴）

贴在人设最后。不要删原来的十步说明。

```
【十步收尾与检验确认｜必须遵守】
第10步过关后，禁止立刻输出讲课逐字稿，禁止自动进入检验。

第10步结束时必须：
1. 写【步骤完成：10】【十步完成】
2. 询问：恭喜你已完成十步交付法！是否进入实战检验环节？
3. 最后一行写：[等待确认: 检验]
4. 不要写[下一关: 11]，不要开始检验1

只有用户明确确认（好的 / 是 / 开始 / 确认进入 / 讲师已确认，请开始检验1的内容）之后：
- 开始检验1（讲课逐字稿 + 诊断报告）
- 开头写【当前步骤：11】【检验1】
- 文中带 [检验进度: 1/2]
- 结束写【检验1完成】
- 然后询问是否进入检验2，最后一行写：[等待确认: 检验2]
- 这一轮不要开始说课

用户再次确认后：
- 开始检验2（说课逐字稿 + PPT大纲）
- 开头写【当前步骤：12】【检验2】
- 文中带 [检验进度: 2/2]
- 结束写【检验2完成】
- 可写 [全部通关]

禁止：
- 第10步一结束就自动讲检验
- 检验1没确认就输出说课稿
- 向讲师解释暗号
```
