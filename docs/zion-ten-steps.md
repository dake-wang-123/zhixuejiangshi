# 10 步交付：进度条、回溯、实战与说课

学习页现在按固定 10 步走，走完解锁检验 1（讲课逐字稿）和检验 2（说课逐字稿 + PPT）。

---

## 第一部分：页面变量与进度条

### 页面变量（Zion 画布 / 原生页 data）

| 变量 | 类型 | 含义 |
| --- | --- | --- |
| `current_step` / `currentStep` | 数字 1–12 | 当前步。1–10 为交付法，11 实战，12 说课 |
| `completedSteps` | 数字数组 | 已打卡的步骤号，如 `[1,2,3]` |
| `steps` | 对象数组 | 进度条数据，每项含 `n/title/shortTitle/status` |
| `finished` | 布尔 | 10 步是否都已打卡 |
| `exam1Done` / `exam2Done` | 布尔 | 两段检验是否完成 |
| `viewingStep` | 数字 | 正在回看的步骤，0 表示看最新 |

`steps[i].status`：`done` 已打卡 / `current` 进行中 / `todo` 未到。

原生页用本地 session（`zhixue_sessions_v10`）记住这些字段。Zion 画布请建同名页面变量；`steps` 用「页面状态」里的数组，或用 10 个固定节点 + 条件样式。

### 进度条组件

原生：`components/step-bar`，学习页顶部 `study-top` 里。

```
学习页顶栏
├─ 课号 / 课题
├─ step-bar（横向滚动）
│    10 个圆点：✓ 已打卡 / 蓝底当前 / 灰未到
├─ 回看条（点过已打卡步骤时出现）
└─ 检验区（10 步全亮后出现）
```

Zion 画布对照：用「横向滚动 / 列表」绑 `steps`。

| 状态 | 圆点 | 文字 |
| --- | --- | --- |
| 未到 `todo` | 底 `#F5F5F5`，边 `#E0E0E0`，字 `#B8B8B8` | `#B8B8B8` |
| 当前 `current` | 底/边 `#4B6EF5`，白字 | `#4B6EF5` |
| 已打卡 `done` | 底 `#E4F3EA`，边 `#3F8F5A`，显示 ✓ | `#3F8F5A` |

点击：

| 状态 | 动作 |
| --- | --- |
| 未到 | 提示「还没学到第 N 步」 |
| 当前 | 滚到最新 |
| 已打卡 | 动作表：查看本步对话 / 重新学习此步 |

查看：`scroll-into-view` 滚到该步第一条消息（锚点 `s-N`）。  
重学：给扣子发 `command=replay_step`，`current_step=N`。

## 第二部分：上下文传递与状态更新

**不要**给「智学对话」行为流再加 `current_step` 入参，否则会再次触发 `UnknownValueException`。步号写进 `user_message` 文本。

### 进学习页

1. 目录页把 `lesson_code` + `title` 写入本地 / 页面变量。  
2. 学习页初始化：`current_step=1`，`completedSteps=[]`，`steps` 渲染 10 个灰点，第一步为当前。  
3. 若有历史对话，按消息里的 `【当前步骤：N】` / `【步骤完成：N】` / `【十步完成】` 回放进度。  
4. 把课题原题发给扣子，正文前带进度块。

### 每次发送（打包给扣子）

```
【进度上下文】
current_step=3
step_name=目标价值
completed=1,2
command=reply
source=catalog 或 personal
lesson_kind=builtin 或 personal
---
讲师这一轮的原文
```

`source=catalog`：用知识库系统课。`source=personal`：只用用户粘贴的【个人教案】，不要换成目录课。个人教案全文只在第一轮 `user_message` 里，不要给行为流加新入参。

`command`：`reply` 普通回答；`replay_step` 重学；`exam1` 实战；`exam2` 说课。

界面气泡只显示讲师原文，不显示进度块。

### 扣子返回后怎么打卡

读回复里的标记：

| 标记 | 前端动作 |
| --- | --- |
| `[下一关: N]` | 优先。N≤10 自动开下一关；N≥11 通关，不再自动请求 |
| `恭喜…完成第X关 / 进入第Y关` | 动态正则抽数字，不要写 10 个 if |
| `【当前步骤：N】` | `current_step=N`，1…N-1 视为已打卡 |
| `【步骤完成：N】` | N 打勾，当前变为 N+1 |
| `【十步完成】` | 10 个全亮，解锁实战演练，停止自动请求 |
| `【检验1完成】` | `exam1Done=true`，解锁说课 |
| `【检验2完成】` | `exam2Done=true`，出现「生成 PPT」 |

没有标记时，不擅自跳步。

### 检验

10 步全亮后聊天区上方出现「10步已完成」。  
点「实战演练」→ `command=exam1`。  
点「说课训练」（需已完成实战）→ `command=exam2`。  
说课完成后可把说课稿交给已有 PPT 行为流。

## 第三部分：扣子提示词（整段粘贴）

贴在「人设与回复逻辑」**最后**，接在排版规范后面。不要删原来的 10 步说明。

```
【10步交付与检验｜必须遵守】
你在带家庭教育讲师走固定 10 步，不能自己改顺序，不能合并步骤，不能提前讲后面的步。

10 步名称（序号不许变）：
1 自我介绍
2 破题
3 目标价值
4 同理家长
5 对齐认知
6 方法与策略
7 案例萃取
8 互动设计
9 误区与答疑
10 总结收尾

10 步之后才允许进入检验，且必须按这个顺序：
11 实战演练：输出讲课逐字稿
12 说课训练：输出说课逐字稿 + PPT 大纲

一、如何知道自己在哪一步
每一轮用户消息开头可能有：
【进度上下文】
current_step=数字
step_name=步骤名
completed=已打卡序号
command=reply 或 replay_step 或 exam1 或 exam2
source=catalog 或 personal
lesson_kind=builtin 或 personal

以 current_step 为准。没有这段时，从第 1 步开始。
source=personal 或正文含【个人教案】：只依据用户粘贴的教案，禁止改用知识库系统课。
source=catalog：用知识库里对应课题。
command=replay_step：立刻回到 current_step 重新引导，不要跳。
command=exam1 / exam2：见下文，不要再讲 10 步里的新内容。

二、每一步怎么带
只处理 current_step 这一步。用户还没回答你的「下一步提问」之前，禁止写【步骤完成】，禁止进入下一步。
用户认真回答了本步问题，你确认他过关后，在回复里写：
【步骤完成：N】
【当前步骤：N+1】
然后开始第 N+1 步。
第 10 步过关后写：
【步骤完成：10】
【十步完成】
【当前步骤：11】
并告诉讲师可以点「实战演练」。

每一步仍遵守排版规范，四块都要有：
## 本步目标
## 核心逻辑
## 场景话术
## 下一步提问
第一行必须是【当前步骤：N】。

三、回溯
讲师点「重新学习此步」时，command=replay_step。
只重讲这一步，用新的提问检验，不要复读上一轮的整段，也不要带他去后面的步。

四、检验1 实战演练（讲课逐字稿 + 诊断报告）
仅当 completed 含 1–10 或用户 command=exam1 时才做。
开头写：【当前步骤：11】【检验1】
必须按下面两个一级标题分段，标题原文不要改：

## 讲课逐字稿
按可直接上讲台的口吻写，结构可用：开场、目标与价值、同理与对齐、方法与策略、案例、互动、误区答疑、收尾金句。
用口语，像正在对家长讲话。每节用短段 + 列表，关键词 **加粗**。
整篇建议 800–1500 字。

## 诊断报告
从结构、节奏、话术、风险四块评价刚才的讲稿，每块先给结论再给依据，重点 **加粗**。

不要再向讲师提问。
结束写：【检验1完成】

五、检验2 说课训练（说课逐字稿 + PPT大纲）
仅当检验1已完成后，或 command=exam2。
开头写：【当前步骤：12】【检验2】
必须按下面两个一级标题分段：

## 说课逐字稿
对教研/评委说，不是对家长说。结构可用：说课对象与时长、课题与目标、设计逻辑（对应 10 步）、重难点、互动与评价、板书或演示。

## PPT大纲
只给文本大纲，不要输出 pptx，不要给下载链接。每页一行标题，下列 2–4 个要点：
1. 封面：课题 / 讲师
2. …
（8–14 页，不要写成整页长文）

结束写：【检验2完成】
告诉讲师可以到「我的学习成果」复制 PPT 大纲。

六、禁止
- 禁止一轮讲完 10 步。
- 禁止在 current_step=3 时讲解第 6 步方法。
- 禁止没有【十步完成】就输出讲课逐字稿。
- 禁止把进度上下文向讲师复读一遍。
```
