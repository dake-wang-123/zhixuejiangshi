# 智学页：未选课空态排版

未选课时顶栏只留一句引导和课程标题输入。顶栏不再放「重新开始」。重置走换课 / 上传教案 / 输入标题，或底部「+」动作表。

---

## 第一部分：Zion 组件操作清单

打开画布 **智学**（学习页）顶栏容器。

| 操作 | 组件 | 怎么改 |
| --- | --- | --- |
| 删除 | 文本按钮「重新开始」 | 从顶栏动作行删掉。不要隐藏占位，直接移除，把高度还给对话列表 |
| 保留 | 文本按钮「再问一次」 | 仅 `error` 有值时可见 |
| 改文案 | 未选课副标题文本 | 删掉「未选课时先给引导语。点课、上传个人教案或输入课题后，按10步走。」 |
| 新文案 | 同一文本组件（或新建引导文本） | 固定文案：你可以在课程目录选择一门课，或者上传个人教案，开始你的十步交付法学习旅程。 |
| 样式 | 上述引导文本 | 字号 14px（28rpx），颜色 `#666666`，行高 1.6，上距 8–16rpx，下距 8rpx |
| 改提示 | 顶栏课题输入框 | Placeholder 改为「输入课程标题」 |
| 不要动 | 底部固定输入条 | 仍绑定 `draft`，圆角、贴底、左侧「+」 |

## 第二部分：引导语要不要绑变量

**不要绑查询、不要绑行为流。** 这是静态文案，按 `course` 是否为空切换可见性即可。

| 页面变量 | 类型 | 用途 |
| --- | --- | --- |
| `course` | 对象 / 空 | 有值 = 已选课或已输入标题 |
| `topicDraft` | 文本 | 顶栏「输入课程标题」的值 |
| `error` | 文本 | 有值才显示「再问一次」 |
| `draft` | 文本 | 底部聊天输入，与引导语无关 |

画布条件：

- 引导语：`course` 为空 → 显示  
- 进度条 / 已选课说明：`course` 非空 → 显示  
- 顶栏标题输入：`course` 为空 → 显示  

不要新增 `guideText` 页面变量，除非你想以后在后台改文案。当前文案直接写在文本组件里。

## 第三部分：没有顶栏「重新开始」之后，何时重置

不要为「重置」新建行为流入参。智学对话仍然只传 `user_message` / `user_id` / `conversation_id` / `bot_id`。

| 场景 | 谁触发 | 画布 / 小程序做什么 |
| --- | --- | --- |
| 课程目录点一门课 | 列表项点击 | 写入待学课号（`lesson_code` + `title`），跳转智学 Tab。页面 `onShow` 换 `lessonCode`，读该课 `learn_message`，没有记录才发课题 |
| 目录顶栏上传个人教案 | 上传成功 | 写入 `P:` 课号和个人教案正文，跳转智学，按新课开会话 |
| 顶栏输入课程标题 | 输入框确认 /「用这题开始」 | 把标题写成 `course`，清空本页未选课会话，按新标题开 `conversation_id` 为空的一轮 |
| 底部「+」→ 重新开始 | 动作表 | 按当前 `lesson_code` 删除该学员 `learn_message`，本地 `conversation_id` 置空，再走未选课引导。**不要**调用带 `lesson_code` 的行为流 |
| 回看条「重新学习此步」 | 进度条 | 只重放某一步，不是整课重置 |

画布若要做「+ / 重新开始」：

1. 动作：删除「智学对话记录」where `课号 = 页面变量 lesson_code`（行权限已限当前用户）。  
2. 动作：页面变量 `conversation_id = ''`，`course = 空`，`topicDraft = ''`，`thread` 清空。  
3. 不要请求智学对话节点去「重置」。下一轮用户发言或未选课欢迎语再请求。

换课不要点重置。目录点课本身就会换 `lesson_code` 并读另一组记录。
