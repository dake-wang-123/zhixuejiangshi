# 智学去掉标题输入，「我的」去掉归档入口

未选课智学不再提供「输入课程标题 / 用这题开始」。开课只走课程目录或「上传个人教案」。各页引导语统一主题蓝 `#4B6EF5`、14px、行高 1.6。「我的」不再出现「课程归档上传」；管理员入口只留在「关于我们」。

---

## 第一部分：删除组件

### 智学页（未选课顶栏）

1. 打开画布 **智学 / 学习页**。
2. 在课名「智学伴练」下方找到：
   - 输入框，Placeholder「输入课程标题」
   - 蓝色按钮「用这题开始」
3. 两个都 **直接删除**，不要改成隐藏。删除后让引导语和对话区自动上收。
4. **不要删**底部固定输入条（`+` / 回复框 / 发送）。那是对话输入，不是开课输入。
5. 不要改「智学对话」行为流入参。没有标题输入后，未选课欢迎语仍只传原来的四个参数。

开课只保留：

- 课程目录点课号
- 分类上方「上传个人教案」展开后提交

### 「我的」页归档模块

1. 打开画布 **我的**。
2. 在底部设置列表找到「课程归档上传」（管理员可见的那一行）。
3. **删除整行**：图标、标题、箭头、点击跳转。
4. 不要删「关于我们」页里的管理员手机号解锁。归档上传只从「我的」拿掉。

---

## 第二部分：引导语颜色与学习记录文案

全局引导语（不是课号、登录态、进度数字）：

| 属性 | 值 |
| --- | --- |
| 颜色 | `#4B6EF5` |
| 字号 | 14px（28rpx） |
| 行高 | 1.6 |
| 字重 | 常规，不要加粗 |

| 页面 | 选中哪个文本 | 新内容 / 颜色 |
| --- | --- | --- |
| 智学 · 未选课 | 大标题 | 智学伴练 |
| 智学 · 未选课 / 选课页 | 蓝色引导 | 从课程目录里选择学习，或者上传你自己的教案，按十步交付法带你吃透课程。`#4B6EF5` |
| 智学 · 已选课 | 课名下蓝色引导 | 十步交付法带你吃透课程，一路通关至模拟讲课、诊断评价、说课训练，最终产出全套逐字稿及PPT框架。`#4B6EF5` |
| 智学 · 已选课 | 课名下第二行 | 一路通关：模拟讲课 · 诊断评价 · 说课训练，产出全套逐字稿及PPT框架。`#4B6EF5` |
| 选课学习 | 英雄区副标题 | 按年龄段分组，用十步交付法吃透每一课。`#4B6EF5` |
| 学习记录 / 收藏 / 帮助 / 关于 | 英雄区副标题 | 原文不动，颜色改 `#4B6EF5` |
| 我的 · 学习记录 | 标题下方小字 | **改为固定文案**「查看已学课程和成果」。不要再绑「还没有学过的课」或课号进度。颜色 `#4B6EF5`，14px，行高 1.6 |

不要改成蓝色的：

- 「微信已登录」、课号、分类未选中态、会员金卡辅文
- 目录页「上传个人教案」那行弱入口（必须比课程列表更淡）

画布操作：选中文本 → 文字颜色 `#4B6EF5` → 字号 14 → 行高 1.6。学习记录小字把绑定或常量改成「查看已学课程和成果」，不要绑查询字段。
