# 选课 / 学习页引导文案

大标题告诉讲师从哪开始，蓝色小字告诉他能拿到什么。方法名一律写「十步交付法」。

---

## 第一部分：Zion 文本组件怎么改

### 选课学习页（课程目录，也是未选课入口）

打开画布 **选课学习 / 课程目录** 顶部英雄区。

| 组件 | 原内容 | 改成 |
| --- | --- | --- |
| 大标题文本 | 选一门课开始学 | **选择你要学习的课题** |
| 蓝色副标题 | 按年龄段分组，用十步交付法吃透每一课。 | **从课程目录里选择学习，或者上传你自己的教案，按十步交付法带你吃透课程** |

智学 Tab 未选课时，主标题仍是「智学伴练」，蓝色引导：你可以在课程目录选择一门课，或者上传个人教案，开始你的十步交付法学习旅程。

### 智学 / 学习页（已选课）

打开画布 **智学**，课名（如「破解分离焦虑：和孩子一起笑着入园」）正下方的蓝色文本。

| 组件 | 操作 |
| --- | --- |
| 原先两行「十步交付法带你吃透课程」+「一路通关：…」 | 合成 **一个** 文本组件 |
| 新内容 | **十步交付法带你吃透课程，一路通关至模拟讲课、诊断评价、说课训练，最终产出全套逐字稿及PPT框架** |

不要绑变量、不要绑查询。这是常量文案。颜色 `#4B6EF5`，字号 14px，行高 1.6。

---

## 第二部分：长句换行怎么配

小程序一行放不下，必须自动折行，不要左右裁切，也不要改成更小字号。

画布文本组件：

| 属性 | 值 |
| --- | --- |
| 宽度 | 铺满父容器（100% / stretch） |
| 自动换行 | 开 |
| 字号 | 14px（28rpx） |
| 颜色 | `#4B6EF5` |
| 行高 | 1.6 |
| 字重 | 常规 |
| 右边距 | 4–8rpx，避免贴边 |
| 上距 | 约 16rpx（课名 / 大标题下方） |

不要用「单行省略 / ellipsis」。不要把一句拆成两个文本组件硬换行；让组件按宽度折行即可。

原生对照：

```css
.guide, .hero-sub {
  display: block;
  width: 100%;
  font-size: 28rpx;
  color: #4B6EF5;
  line-height: 1.6;
  white-space: normal;
  word-break: break-word;
}
```
