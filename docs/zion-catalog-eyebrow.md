# 课程首页：去掉「60 堂系统课」

眉题「60 堂系统课」和下面的「7 个类别 · 60 门系统课」重复。只留后者。智学未选课主标题恢复「智学伴练」。

---

## Zion 操作步骤

打开画布 **选课学习 / 课程目录** 顶部英雄区。

1. 选中灰色小字 **「60 堂系统课」**（通常是英雄区最上面一行，在大标题「选择你要学习的课题」之上）。
2. **直接删除**这个文本组件。不要改成隐藏占位，否则会留下一行空白。
3. 确认下面这行还在，并且是动态绑定，不是写死的「60 堂」：
   - 文案：`{{类别数}} 个类别 · {{课程数}} 门系统课`
   - 小程序对应：`{{categoryCount}} 个类别 · {{catalogCount}} 门系统课`
4. 不要改这行的字号和颜色（保持 12px / `#999999`，作为分类区总览）。
5. 删除后检查英雄区与分类 chips（全部 / 0-3岁…）之间：上距约 8–12rpx 即可，不要再加额外 Spacer。

打开画布 **智学**（未选课）：

| 组件 | 改成 |
| --- | --- |
| 大标题 | **智学伴练** |
| 标题下蓝色引导 | **你可以在课程目录选择一门课，或者上传个人教案，开始你的十步交付法学习旅程。** |

已选课课名下的结果说明不要动。
