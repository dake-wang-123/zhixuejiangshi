## 第二部分：折叠交互与页面变量

**不要新建行为流，也不要给「智学对话」加参数。**

| 页面变量 | 类型 | 默认 | 用途 |
| --- | --- | --- | --- |
| `plan_open` | 布尔 | false | 控制教案表单展开 |
| `plan_title` | 文本 | 空 | 教案标题 |
| `plan_text` | 文本 | 空 | 教案正文 |
| `plan_file_name` | 文本 | 空 | 可选，从文件填入后的文件名 |

画布动作：

1. 弱入口点击 → 设置 `plan_open = true`。只改页面变量，不请求接口。  
2. 「收起，先看下面的系统课」→ `plan_open = false`。  
3. 「开始十步交付法」→ 校验 `plan_text` 非空 → 写入待学课号（`P:` + 标题）和正文 → 跳转智学 Tab。正文仍放进之后的 `user_message`，**不要**新增行为流入参。  
4. 分类 chips、点课号：逻辑不变。点课写入 `lesson_code` + `title`，跳转智学。

智学进度条：

- 点击节点：已有事件「步骤变更」→ 回看该步对话。  
- 「重新学习此步」：已有动作，重放该步。  
删掉顶栏那句说明后，这两条事件保持原绑定即可。
