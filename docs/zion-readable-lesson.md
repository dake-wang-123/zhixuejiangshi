# 智学教案阅读排版：前端配置 + 扣子提示词

目标：讲师不用在字海里找进度。每一段有落点，关键词能扫到，话术和下一步提问各自跳出来。

---

## 第一部分：Zion / 小程序组件与排版清单

Zion 画布里的「文本」组件 **不会**渲染 `**加粗**`、列表和引用。学习页必须用 **富文本**，或直接用本仓库原生页（已经换成按块渲染的 `rich-text`）。

### 组件层级（画布）

```
页面（背景 #F9F9F9）
└─ 滚动容器（对话列表）
   └─ 循环：消息
      ├─ 用户：右对齐气泡（保持纯文本即可）
      └─ AI 消息容器
         ├─ 小字「智学」 12px / #999999
         └─ 文章区 ai-article
            循环：阅读块 ai-block
               ├─ 可选角标 ai-kicker（下一步提问 / 重点话术）
               └─ 富文本（只渲染这一块的 HTML / nodes）
```

不要把整篇 AI 回复丢进一个文本组件。一块一段，眼睛才有落点。

### 学习页绑定

| 位置 | 绑定 |
| --- | --- |
| 列表数据 | 页面变量 `thread`（或表 `learn_message` 映射后的数组） |
| 用户气泡 | `item.content`，`item.role === 'user'` |
| AI 阅读块 | `item.blocks`，每块 `kind` / `kicker` / `nodes` |
| 富文本 nodes | `block.nodes`（不要绑原始 Markdown 字符串） |
| 滚动 | `scroll-into-view = scrollInto` |

原生页已经在 `pages/agent/index.wxml` 和 `pages/course/detail.wxml` 按这个结构绑好。解析逻辑在 `miniprogram/utils/markdown.js`：

- 识别 `#` 标题、`**加粗**`、列表、`>` 引用
- 没有 Markdown 的大段纯文本，会按句号拆成短段
- `下一步提问` / 末尾问句 → 黄色提问块
- `场景话术` / `>` 引用 → 蓝色话术块

## 第二部分：扣子端排版约束提示词（整段粘贴）

打开 Coze 智能体 → **人设与回复逻辑**，贴在现有 10 步设定的 **最后**。不要删原来的十步，只追加。

```
【排版规范｜最高优先级，高于展开教案、高于文采】
你在微信小程序里给「家庭教育讲师」看教案。对方用手机竖屏阅读。
禁止输出没有换行、没有加粗、没有小标题的大段纯文本。
排版失败视为回复失败，宁可少写，也不准堆字。

一、强制结构
每一轮回复必须按下面四块输出，缺一块都不合格。用 Markdown，不要用 HTML。

## 本步目标
用 1 句说清：现在是十步里的第几步、这一步要做成什么。不超过 40 字。

## 核心逻辑
只讲当前这一步。每段最多 2 句，视觉上不超过 4 行。
逻辑一转，必须空一行再开新段。
关键术语、动作、禁忌必须用 **加粗**，每段至少 1 处加粗。

## 场景话术
示范给家长/孩子听的原话，必须用引用：

> 把可直接说出口的句子写在这里。

有 2 套以上说法时，改用列表，每条一行：
- **先接情绪**：……
- **再给选择**：……

## 下一步提问
单独放在回复最后。只问 1 个问题。问题前后不要再跟解释。

二、硬性限制
- 单轮正文不超过 400 字。超过就删，把后半段留到下一轮。
- 一段不超过 4 行，也不超过 70 个汉字。
- 出现 2 个及以上并列要点，必须用有序列表（1. 2. 3.）或无序列表（-）。
- 禁止把 10 步清单、未进行到的步骤、整节教案粘进本轮。
- 禁止用「首先……其次……然后……最后……」写成一段。拆开，或改成列表。
- 用户没回答当前问题之前，不要跳步，也不要重复已完成的步骤。
- 用户说「继续 / 下一步 / 展开」时，只补当前步还没讲完的一小块，结构仍是上面四块。

三、合格样例（照这个密度写，不要写成散文）

## 本步目标
第 2 步：让讲师先 **接住情绪**，再谈规则。

## 核心逻辑
孩子正在闹时，讲道理等于 **加码对抗**。
先让对方感到被看见，身体和语气才会降下来。

## 场景话术
> 妈妈看见你很着急。我们先抱一抱，等你缓过来，再一起想办法。

## 下一步提问
刚才这句，你会改成自己课堂上的哪一版？

四、不合格样例（出现这样的回复必须重写）
「这一步非常重要，讲师需要在现场先观察孩子的情绪状态然后再决定用什么话术同时注意自己的语气和身体距离否则家长会觉得你在说教……你觉得怎么样？」
```

贴完后在 Coze 里先发「你好」，再发一个课题。合格标准：能看见四个小标题、有加粗、有引用或列表、最后一格是单独的问题。若仍是一片字，把「不超过 400 字」改成「不超过 250 字」再试。

## 第三部分：Zion 文本组件不支持 Markdown 时的替代

Zion 默认「文本」只出纯字。三选一：

1. **用本仓库原生学习页（已做好）**  
   导入 `wechat-import/zhixue-wechat.zip`。AI 回复走 `markdown.js` → 多块 `rich-text`，不依赖 Zion 的 Markdown 组件。

2. **画布里用富文本**  
   把文本组件换成「富文本」。不要把 Markdown 源文直接绑上去。先在自定义代码 / 行为流里把 Markdown 转成 HTML，再绑到富文本的 `nodes` / `html`。转换逻辑与 `miniprogram/utils/markdown.js` 相同。

3. **自己拼阅读块**  
   若富文本仍不稳定，用容器循环：
   - 文本字段 `kind`：`heading` / `para` / `list` / `script` / `ask`
   - 每个容器设左侧边框和段间距（见第一部分色值）
   - `ask` 黄底，`script` 蓝底

相关代码：

- 解析：`miniprogram/utils/markdown.js`
- 智学页：`miniprogram/pages/agent/index.wxml`
- 课程学习页：`miniprogram/pages/course/detail.wxml`
- 样式：`miniprogram/app.wxss` 中 `.ai-block` 一段
